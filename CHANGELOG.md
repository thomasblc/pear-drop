# Changelog

## 1.0.9

- First public version of the desktop app.
- Send files or folders with a `peardrop://` link and QR code, receive by pasting a link.
- Nearby devices behind the same public IP, one-click send.
- Neutral default device name, bundled fonts, macOS quarantine flag on received files.
- Resumable transfers, several peers can seed the same files.
- Over-the-air updates with Pear: in-app "New version ready · Restart" prompt with a download progress bar.
